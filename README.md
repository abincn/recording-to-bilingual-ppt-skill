# Recording to Bilingual PPT — Muse Skill

Turn a lecture recording into a bilingual (Chinese-English) PPT where
every slide carries the lecturer's own cleaned-up voice, with bilingual
subtitles that never cover the slide text, never split a sentence, and
are centred in the subtitle bar so the player controls cannot hide the
Chinese line.

Read `SKILL.md` for the full playbook. Scripts in `scripts/` are the
generic tools it describes: `make_ass.py` (bilingual ASS, middle-centre),
`build_ppt.py` (clean python-pptx assembly), `make_videos.sh` (ffmpeg
template).

No recording, transcript, credential, or personal file is included.
